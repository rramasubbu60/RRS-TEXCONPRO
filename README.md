# RRS TEXCONPRO

Textile consultancy records, billing and reports for R. Ramasubramanian, Textile Consultant, Dindigul.

- `site/` – the app (published by Netlify as-is, no build step)
- `supabase/setup.sql` – one-time database setup (run in Supabase › SQL Editor)

Netlify: Add new site › Import from GitHub › pick this repository. Netlify reads `netlify.toml` and publishes the `site` folder. Every push to `main` redeploys automatically.
